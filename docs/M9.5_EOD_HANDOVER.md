# M9.5 EOD Handover

> M9.5 — openlaude runtime upgrade (pydantic-ai + pydantic-graph + instructor).
> Single squash commit lands all six phases. Pickup notes below.

## Shipped

* **Phase 1 — setup.** `[agent]` extra in `pyproject.toml` (pydantic-ai,
  pydantic-graph, instructor). Inline spike `_pydantic_ai_spike.py`
  verifies the import + Ollama path; host offline so spike returns
  `SPIKE_DEFERRED: ollama_offline`.
* **Phase 2 — tool migration.** `vibedump/agent/tools.py` rewritten on
  `ToolDefinition(Generic[InputT])` with 9 Pydantic input models.
  `registry.dispatch()` validates via `model_validate(...)` and wraps
  `ValidationError` in `ToolError(name, ...)`. 25 tool tests green.
* **Phase 2b — core refactor.** `OpenClaude(bus=...)` accepts an
  optional EventBus. `PydanticAIBackend` wraps `pydantic_ai.Agent` via
  the `OpenAIChatModel` + `OpenAIProvider(base_url=..., **{"<auth-kwarg>": "ollama"})`
  stack (auth kwarg name omitted from prose per project naming policy).
  Inline loop remains the canonical path; `_HAS_PYDANTIC_AI` flag
  toggles backend at runtime. 13/13 core tests.
* **Phase 3 — pipeline graph.** `vibedump/agent_pipeline.py` adds a
  parallel `GraphPipeline` with `DumpState`, `DraftNode`,
  `ListeningNode`, `ThinkingNode`, and a SQLite-backed
  `PipelineStatePersistence` that maps onto the existing
  `dumps.metadata_json` column. New `Database.update_dump_metadata(...)`
  helper. 20/20 pipeline tests.
* **Phase 4 — listener structured output.** `ListenerDecision`,
  `BlueprintSection`, `Blueprint` are now Pydantic models (frozen).
  `parse_listener_response_structured(...)` is the new entry point
  that tries `instructor` first and falls back to the regex parser
  when instructor is missing. 24/24 listener tests.
* **Phase 5 — telemetry.** `OpenClaude._publish_trace(...)` publishes
  the `agent.trace` SSE event on the bus. Payload: `steps`,
  `duration_ms`, `model`, `tool_call_count`, `tool_calls`,
  `final_message_preview`. Best-effort; never breaks the run.
  `app.py:_wire_agent_runtime` now passes `bus=state.bus` to the
  agent. Dashboard subscribes to `agent.trace` and renders a
  collapsible Trace panel (last 50 runs). 6/6 telemetry tests.
